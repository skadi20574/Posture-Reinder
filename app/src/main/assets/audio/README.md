# 语音文件

仓库里**不包含**任何 MP3。App 在没有音频文件时会自动退回系统 TTS（`TextToSpeech`，中文），
所以直接编译也能出声；想要更自然的提示音，把下面这些文件放进来即可（文件名必须一致）：

```
sit_up.mp3    坐直一点，背挺起来。
head_up.mp3   头抬高一点，别低头。
shoulders.mp3 肩膀放平，放松一点。
center.mp3    身子往中间坐一坐。
far.mp3       离书远一点，让眼睛休息一下。
sit2.mp3      背挺直，坐正一点。
near.mp3      离书太近了，抬头看看远处。
rest.mp3      坐了很久啦，起来活动一下。
good.mp3      很好，就这样保持。
focus.mp3     看前面，专心写作业哦。
distract2.mp3 别走神，继续写吧。
eyes.mp3      眼睛累了吧，闭眼休息一下。
eyes2.mp3     眼睛累了就闭会儿眼吧。
away.mp3      回到座位继续写吧。
covered.mp3   摄像头好像被挡住了，检查一下。
praise.mp3    这一会儿坐得很好，继续保持。
back.mp3      坐得有点靠后了，往前坐一点。
```

录制或合成的音频请确认版权允许随本项目一起分发。
